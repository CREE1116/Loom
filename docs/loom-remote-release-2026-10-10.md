# Loom 0.1.1 리모트 완성 및 배포 검증

2026-10-10. `/remote`는 실행 중인 Loom 대화를 폰 브라우저에서 조작하는 기능이다.
컴퓨터의 Loom이 실제 작업을 실행하며 폰은 대화와 상태를 보고 요청·응답을 보낸다.

## 완료한 흐름

- `/remote`: QR 주소 표시. `cloudflared`가 있으면 임시 HTTPS 주소 준비.
  준비 지연·종료·실패를 확인하고 로컬 주소를 유지한다.
- `/remote local`: 같은 네트워크용 HTTP만 사용. `/remote off`는 리스너,
  대기 중인 조회, 아직 읽는 요청과 터널을 종료한다.
- 폰에서 메시지 전송·대기열 등록·중단·승인·질문 선택·직접 입력·질문 취소.
  모델·추론 수준 선택, 대화 압축과 새 대화도 지원한다.
- 컴퓨터 초안의 커서·선택·이미지·스킬·붙여넣기 상태를 원격 메시지와 분리한다.
  비밀 질문은 입력 형태만 공유하며 컴퓨터에 작성 중인 답변을 내보내지 않는다.
- HTTP 성공은 창이 실제 요청을 받아들인 뒤 반환한다. 오래된 질문·승인,
  지원하지 않는 모델·추론 수준과 실행 중 금지된 동작은 이유를 돌려준다.
- 요청 식별자를 최근 128건·최대 5분 보관해 응답을 잃은 요청의 재시도가
  같은 작업을 다시 만들지 않도록 한다. 폰에서 자동 재전송하지 않는다.
- 읽는 도중 나눠 도착한 요청도 처리하고 헤더·본문·동시 연결에 상한을 둔다.
  최근 조회 기록으로 브라우저 수를 표시해 매 조회 완료마다 연결이 끊긴 것처럼
  보이지 않게 한다.
- 폰 화면의 실패 입력 복구·승인 재시도·연결 복구·질문 입력·좁은 화면을 검사한다.

## 실행과 제약

QR 창만 닫으면 서버는 켜져 있다. `/remote`로 QR 창을 다시 열 수 있다.
서버를 다시 켜면 토큰이 바뀌며 임시 인터넷 주소도 바뀔 수 있으므로 새 QR을 스캔한다.
홈 화면 바로가기는 해당 주소에 연결된다. Loom 종료 후 독립 실행하거나
오프라인에서 작업하는 앱은 아니다.

원격 화면은 최근 200개 대화 항목을 표시하며 도구는 상태·제목 중심으로 묶는다.
일반 메시지란의 슬래시 명령은 `/plan 목표`를 제외하면 거절한다. 모델 변경·압축·
새 대화·중단은 원격 메뉴를 사용하고 다른 명령은 컴퓨터 창에서 실행한다.
현재 연결 대상은 열린 대화 하나다.

대화·조작 API에는 랜덤 토큰이 필요하며 주소를 가진 사람은 세션을 조작할 수 있다.
설치용 페이지·아이콘·manifest에는 대화 데이터가 없다. 로컬 HTTP에는 암호화가 없고,
인터넷 주소에는 HTTPS 터널을 사용한다.

## 검증

macOS에서 다음을 확인했다.

| 검사 | 결과 |
| --- | --- |
| Core 전체 테스트 | 469 통과, 0 실패, 기존 25 ignored |
| TUI 전체 테스트 | 330 통과, 0 실패, 기존 3 ignored |
| 리모트 회귀 검사 | 13 통과. 마지막 입력 검증 변경도 재검사 |
| Chromium 폰·데스크톱 상호작용 | 13 통과. 전송 실패·중복 방지·승인 재시도·질문·재연결·모델·메뉴·320px 화면·입력·만료·시간초과 |
| 배포 바이너리 화면 검사 | 849 검사, 0 실패. QR·초안 보존·원격 질문 포함 |
| 실제 TUI↔HTTP 서버 연동 | 배포 바이너리의 승인 응답·전송·중복 재시도·로컬 초안·거절·중단·종료 통과 |

폰 브라우저 검사는 실제 HTML을 가상의 HTTP 상태 서버에 연결해 실행한다.
서버·창·백엔드 전달은 별도의 실제 TUI 검사로 확인하며, 두 검사를 혼동하지 않는다.
자동 검사에서 실제 모델 요청과 외부 터널 접속은 하지 않는다.

실제 TUI와 서버 통합은 `python3 loom-tui/tests/remote_smoke.py`로 검사한다.
폰 브라우저 검사는 Playwright 설치 경로를 `PLAYWRIGHT_MODULE_PATH`로 지정한 뒤
`node --test loom-tui/tests/remote_browser.mjs`로 실행한다.
CI는 macOS·Linux·Windows의 두 crate 검사와 화면 검사, 별도 Chromium 검사를 실행한다.

## 함께 배포하는 변경

명령 검색, 파일 패턴·내용 검색 도구, LMX 대기 취소, 작업용 기본 스킬은
[제품 개선 기획](loom-product-improvements-2026-10-10.md)에 구현과 후속 계획을 구분했다.
Windows의 작업 폴더 타임스탬프 설정은 필요한 쓰기 권한으로 파일을 열어 처리한다.
원본 내용과 수정 시간 보존을 별도 회귀 검사로 확인한다.

네이티브 모델의 속도 개선율, 실제 스마트폰의 홈 화면 설치와 외부 HTTPS 터널의
운영 가용성을 자동 검사 결과로 주장하지 않는다.
