# Loom v0.1.4

코드 탐색 도중 도구 오류가 반복되고 토큰 제한으로 작업이 멈추던 문제를 수정합니다.

- 기본 작업의 숨은 누적 입력·출력 16만 토큰 제한을 제거합니다. 명시적으로 설정한 요청 횟수·시간 한도와 모델 제공자의 문맥·사용량 한도는 계속 적용합니다.
- 빈 검색 범위 `scope: ""`를 저장소 전체 검색으로 처리합니다. 지정한 파일·디렉터리·심볼 범위는 유지합니다.
- 파일 읽기의 끝 범위가 파일 길이를 넘으면 실제 끝까지만 읽고 전체 줄 수와 실제 범위를 반환합니다. 시작 범위 오류와 400줄 제한은 계속 검사합니다.
- 시작 줄만 지정한 파일 읽기가 해당 줄부터 동작합니다.
- 큰 클래스·타입은 본문 대신 페이지 단위 AST 멤버 목록을 반환합니다. 검색 결과에 심볼 종류와 줄 범위를 포함해 필요한 메서드를 바로 읽을 수 있습니다.
- 심볼 읽기에서 명시한 파일 줄 범위를 무시하던 문제를 수정합니다. 동일 소스를 재조회해도 모델 문맥에는 최신 사본 하나만 유지하고 원본 실행 로그는 보존합니다.
- Loom에서 새 대화·재개·분기를 열어도 직접 선택한 모델을 유지합니다. 네이티브 런타임의 대화별 모델 설정은 유지합니다.
- 붙여넣기·파일 첨부 이미지를 Core와 이미지 지원 모델에 전달합니다. 이미지 단독 요청도 지원하며 작업 중 문맥 압축으로 첨부가 사라지지 않습니다.
- Windows CI의 공통 시간 제한 검사를 명령 시작 지연에 덜 민감하게 수정합니다. 시간 제한과 늦은 명령 실행 방지 검사는 유지합니다.

v0.1.3 사용자는 자동 업데이트 또는 `loom update`로 설치한 뒤 재시작할 수 있습니다.
이전 버전은 설치 명령을 한 번 다시 실행해주세요.
