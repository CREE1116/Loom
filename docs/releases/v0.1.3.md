# Loom v0.1.3

macOS Apple Silicon, Linux x86_64, Windows x86_64용 실행 파일을 함께 배포합니다.

- 설치된 Loom이 하루 한 번 업데이트를 확인하고 다운로드를 검증합니다. macOS·Linux는 설치 후 재시작하고, Windows는 종료 후 교체합니다.
- `loom update`, `loom update --check`, `LOOM_AUTO_UPDATE=0`을 지원합니다.
- 훅이 도구 실행·프롬프트·세션·하위 에이전트·대화 압축 이벤트를 처리하며, 에이전트의 기본 지침에도 사용법을 포함합니다.
- 여러 스킬을 요청 안에서 함께 지정할 수 있습니다.
- 도구 기록에 전체 명령과 실제 출력을 표시합니다.
- 릴리스는 세 플랫폼의 테스트와 패키지 검증이 모두 성공한 뒤 공개합니다.

v0.1.3 이전 설치에는 자동 업데이트 기능이 없으므로 설치 명령을 한 번 다시 실행해주세요.
Linux 바이너리는 glibc 2.39 이상이 필요합니다. 이전 배포판과 다른 아키텍처는 소스 빌드를 이용할 수 있습니다.
CUDA 직접 빌드는 자동 교체하지 않습니다. 설정·모델·대화 기록은 유지합니다.
