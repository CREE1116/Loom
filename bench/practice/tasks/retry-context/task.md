작은 실행 루프가 오류 한 번에 작업을 포기하는 문제를 고쳐줘.

`src/engine.rs`의 공개 자료형과 함수 API를 유지하면서 다음 동작을 구현해줘.
- ModelError::Transient만 같은 문맥으로 재시도해. 한 요청의 연속 시도는 최초 호출
  포함 최대 3회야. 성공 응답을 받으면 연속 실패 횟수를 초기화해.
- ModelError::Auth는 즉시 반환해. 모든 실제 모델 호출은 max_calls에 포함해야 해.
- 도구가 실패하면 오류를 `ERROR: `로 시작하는 문맥 항목으로 모델에 전달하고,
  다음 요청에서 수정을 시도할 기회를 줘. 실패한 편집을 성공했다고 기록하면 안 돼.
- 완료한 읽기·편집은 모델 연결 오류 때문에 다시 실행하거나 초기화하지 마.
  이전 도구 결과와 이미 편집한 파일도 보존해야 해.
- Report의 model_calls는 실제 호출 수, tool_calls는 성공·실패를 포함한 도구 시도 수야.
- 한도나 반복 실패에 도달하면 멈춰. 무제한 반복과 문자열로 오류 종류를 추측하는
  처리를 넣지 마.

`cargo test --offline`으로 검증하고, 일시적 모델 오류와 도구 오류를 어떻게 다르게
처리했는지 설명해줘. 실행 중 실제 네트워크 호출이나 sleep은 필요 없어.
