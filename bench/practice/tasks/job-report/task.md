작업 기록을 한눈에 볼 수 있는 한국어 요약 기능을 완성해줘.

`src/model.rs`의 Job과 Summary API를 유지하고 `src/summary.rs`의 집계,
`src/render.rs`의 화면용 문자열을 구현해줘. 서로 독립적으로 처리할 수 있는 부분은
분리해도 되지만 워커 수를 늘리는 것 자체가 목표는 아니야.

요구사항:
- Success / Failed / Cancelled를 각각 완료 / 실패 / 중지로 집계해.
- 시간과 토큰 합계는 모든 작업 기록을 포함해. u64 합계는 overflow 시 MAX로 포화해.
- 입력·출력 토큰은 각각 따로 계산해. 어느 기록이라도 해당 값이 None이면 그 합계도
  None이야. 보고되지 않은 사용량을 0으로 취급하면 안 돼. 빈 목록의 합계는 Some(0)이야.
- 출력 형식은 정확히 두 줄이야. 끝에 줄바꿈은 붙이지 않아.
  `완료 2 · 실패 1 · 중지 1`
  `시간 140ms · 입력 미보고 · 출력 12`
- 토큰 합계가 Some이면 숫자만, None이면 `미보고`로 표시해.
- 샘플에만 맞춘 하드코딩을 하지 말고 서로 다른 기록으로 회귀 테스트를 추가해.

`cargo test --offline`과 `cargo run --offline -q`로 확인하고 변경 결과를 설명해줘.
